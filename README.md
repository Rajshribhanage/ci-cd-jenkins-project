# CI/CD Jenkins Automation Project

## Project Overview
This project demonstrates a CI/CD pipeline using:
- Jenkins
- Maven
- Selenium WebDriver
- TestNG
- GitHub

The Jenkins pipeline automatically:
1. Pulls code from GitHub
2. Cleans workspace
3. Builds the project
4. Executes Selenium test cases

---

## Technologies Used
- Java
- Selenium WebDriver
- Maven
- Jenkins
- TestNG
- GitHub
